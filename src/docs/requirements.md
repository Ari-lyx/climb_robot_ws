# 磁吸球罐内壁机器人：需求与实现边界

## 目标与包职责
- `robot_description`：长方体底盘、左右各两个圆柱轮，四个连续转动关节；尺寸、质量、轮距、轴距、摩擦、动力参数均通过 YAML → Xacro 配置。顶部安装激光雷达。
- `third_party`：第三方雷达接入宏、依赖出处与许可证；使用系统安装的 Velodyne VLP-16 网格和 ROS 2 点云插件，不复制无来源资源。
- `gazebo_models`：本地生成带真实厚度、内外表面和封口边缘的球罐网格。默认下半球开口，便于看内部；另有完整球壳和地面场景。不依赖在线模型下载。
- `robot_control_driver`：四轮扭矩驱动与磁吸 Gazebo ModelPlugin，接收 `/cmd_vel`，发布三维仿真真值 `/odom`、TF、轮关节状态、磁吸诊断，提供磁吸开关。
- `climb_robot_bringup`：统一 launch、集中配置、启动姿态计算、验证脚本。

## 物理约定
1. 世界重力固定 `(0, 0, -9.81) m/s²`。不随机器人朝向改变；不直接修改车体位姿、速度，不使用平面运动插件或固定关节吸附。
2. 每轮分别向球壳内壁法线外向施力（球内朝向球心的反方向）。静止钢壳作为刚性固定环境，其反力由环境支撑承担；不模拟可移动罐体。
3. 有效轮面间隙 `g = R - |p_wheel - center| - h`，`h` 是圆柱沿壁面法线的支撑长度，包含轮宽和轮轴倾斜。
4. 近场力 `F = F_contact / (1 + max(g,0)/decay_length)^2`，在捕获距离末段平滑降至零。吸力有上限，无远距离吸附；磁吸关闭、球壳不存在、移出开口或间隙超过捕获距离时为零。
5. 接触反力由 ODE 球壳三角网格与圆柱轮碰撞产生，摩擦决定牵引与滑移。电机仅通过关节扭矩驱动，速度命令有超时、限速与扭矩限制。
6. 球壳的半径、类型由生成模型中的元数据读取，跟随球罐模型位姿。磁力使用解析球面近似，碰撞使用细分网格；二者有毫米级离散误差。边缘附近不构成准确的磁场模型。
7. 此为运动与附着能力仿真，不是磁场有限元或磁铁选型依据；不包含磁滞、钢板饱和、漏磁、轮胎柔性、独立悬架、焊缝碰撞或结构应力。

## 默认几何与坐标
- 车体 x 向前、y 向左、z 向上；轮轴 +y。四轮固定安装、左右组差速（滑移转向）。
- 内半径 3 m，厚度 0.06 m，球心高度 3.15 m；下半球开口位于球心高度。
- 出生角 `spawn_angle_deg` 从球底沿 +x 方向测量：0° 为底部，90° 为竖直壁面，180° 为顶端。完整球壳用于 >90° 场景。
- 所有数值集中在 `climb_robot_bringup/config/simulation.yaml`。更改几何后启动器同步重建碰撞网格、URDF 和出生位姿。

## 验收
- 五个包可通过 colcon 构建；Xacro/SDF 可解析。
- 地面场景：无磁力，速度命令驱动前进和转弯。
- 球壳场景：四轮存在独立磁吸诊断，爬坡时高度增长；竖直壁面可附着，关闭磁吸后下落。
- 完整球壳：顶端可附着，关闭磁吸后受重力掉落。
- `/velodyne_points` 有点云，TF 包含雷达和四轮；里程计保留完整三维姿态（仿真真值，不宣称轮式定位精度）。
- 停止发布命令后电机进入零速制动目标；不代表断电自由滑行。

## 不在首版范围
SLAM、Nav2、全覆盖路径规划、真实 CAN/串口驱动、ROS 2 Control 硬件抽象、动态罐壁、磁铁电磁场求解。半球开口之外没有可吸附的虚拟墙壁。

## 实现依据
- [Gazebo Classic ModelPlugin](https://classic.gazebosim.org/tutorials?cat=write_plugin&tut=plugins_model)：逐物理步施力与插件加载。
- [Velodyne simulator](https://index.ros.org/p/velodyne_simulator/)：VLP-16 模型和点云传感器插件；具体采用本机 Humble 安装文件。
- 本机平台为 ROS 2 Humble + Gazebo Classic 11，本工程针对该已有平台构建。

## 视觉焊缝扩展

- 新增独立 `welds.py`，生成沿球面朝内凸出的半椭圆截面焊缝，配银灰色程序化鱼鳞纹理；罐壁为可配置棕褐色。
- 环向焊缝划分板带，各板带内纵向焊缝可设置条数与错缝角度，两极保留封头。适配下半球与完整球壳，地面场景不生成焊缝。
- 当前仅视觉层：不改变球壳碰撞、磁力计算或 CPU ray 激光返回，不承担越焊缝运动验证。
